# Project Rules

- **Sistema da Agenda**: A partir de 10 de Agosto de 2026, **NÃO** faça mais alterações no sistema da agenda e no funcionamento de agendamentos. **O design (visual, HTML, CSS e layout) da agenda também está estritamente bloqueado e não deve ser modificado em hipótese alguma.** Esse sistema já está fechado e consolidado pelo usuário. **EXCEÇÕES: (1) Adicionar um botão de Editar no modal de Detalhes do Agendamento é permitido. (2) A partir de 23/08/2026, a paleta de cores dos blocos da agenda (variáveis --agenda-c1..c7 no style.css) pode ser alterada para ficar consistente com as cores de destaque usadas no restante do site — layout/estrutura da agenda continuam bloqueados.**
- **Sistema do Kanban**: O funcionamento central, a lógica e o banco de dados do Kanban **NÃO** devem ser alterados de forma estrutural. É permitido realizar alterações **apenas no Front-end (Visual, HTML, CSS)** e na experiência do usuário na tela do Kanban, mas sem quebrar as funcionalidades já existentes.

Permita que possa altere o tooltip modal da agenda.
